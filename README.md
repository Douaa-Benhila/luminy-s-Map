## Présentation du Projet : LUMIN'S MAP

###  À quoi sert ce projet ?

**LUMIN'S MAP est une application web interactive qui permet de se diriger facilement dans les bâtiments de l'Université d'Aix-Marseille, campus de Luminy.**

On choisit un point de départ et un point d'arrivée, et l'application affiche sur une carte le chemin le plus court. C'est une version minimale d'un Google Maps, dédiée au campus. Ce projet mêle développement web front-end et back-end.

---

### Technologies utilisées
- **Front-end** : HTML, CSS, JavaScript
- **Back-end** : Python avec Flask
- **API** : Google Maps API
- **Versioning** : GitLab

---

###  Lancer le projet

1. Installer Flask :

```bash
pip install flask
```
2. Lancer le script `app.py` :

```bash
python app.py
```

3. Ouvrir [http://127.0.0.1:5000](http://127.0.0.1:5000) dans le navigateur.

4. **Pour vous connecter**, il faut d'abord créer un compte : renseignez un nom d'utilisateur et un mot de passe de votre choix (n'importe lesquels), puis connectez-vous avec.
